# Personal Portfolio Risk Analyzer

A beginner-friendly Python project that analyzes a sample investment portfolio using historical price data.

## What it does
- Calculates daily and annualized returns
- Calculates annualized volatility
- Estimates portfolio return and volatility
- Compares individual assets
- Creates a portfolio growth chart

## Tools
- Python
- pandas
- numpy
- matplotlib

## Run
```bash
pip install -r requirements.txt
python portfolio_analyzer.py
```

The project uses a small included CSV dataset so it can run without an external API.
